# LOVE ALL — The match is off

Scoped React source for the Nancy tennis world. The repository root Toybox board is separate.

Use Node 22.13 or newer. Run `npm ci`, then `npm run build`. The static site is produced in `pages-dist/`; copy its contents to the repository’s `tennis-world/` folder to publish. `npm run dev` opens the static development target.

The experience includes eleven Higgsfield films, original Nancy product photography, a playable Three.js court loaded on demand, a film scrubber, and campaign portraits with product-view switches. All required media and fonts are included in `public/`. Videos pause offscreen and behind dialogs. Global pause and reduced motion are supported.

The deployment base is `/nancy-toybox/tennis-world/`. No environment variables, backend or credentials are required. The underscore prefix keeps this source directory out of the existing Jekyll Pages site.

Campaign product images are art-directed interpretations; use the Product view for the original official photographs. This is an independent Nancy creative concept.
