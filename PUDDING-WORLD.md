# Nancy Pâtisserie

Public campaign: https://rsquaredboi.github.io/nancy-toybox/pudding-world/

A dessert salon with three Higgsfield films, an interactive silver cloche, original product views, selectable salon scenes and a souvenir generator. Includes motion controls and responsive layouts.

The deployed site is in `pudding-world/`; reproducible source is in `_pudding-world-source/`. See the source README for build instructions. The root Toybox board and tennis-world site are separate.

This is an independent creative prototype. Shopping links lead to the existing Hello Nancy store. Product pricing, stock and checkout are not integrated.
